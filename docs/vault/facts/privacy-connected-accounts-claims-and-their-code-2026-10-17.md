## Not claimed, on purpose

The page lists no Instagram permission names: the dialog sends a scope list unless `META_LOGIN_CONFIG_ID` is
set, and then the permission set is the Meta dashboard's, which the repo cannot show
(`apps/web/src/lib/social-oauth.ts:151-170`). It names no time for the daily check (the first hourly tick
after 00:00 UTC, whenever the box is up). It asserts no transfer basis for Meta, TikTok or Resend.
